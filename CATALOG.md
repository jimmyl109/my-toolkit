# Catalog

Enable id format: `<plugin>@my-toolkit` under `enabledPlugins`. See README for the full settings example.

| Plugin | Type | Description | Trigger words | Enable id |
|--------|------|-------------|---------------|-----------|
| core | always on | Planner, code/security reviewers, TDD and build-error agents; skills for TDD, security review, verification, coding standards, ponytail; common rules injected at session start | every project | `core@my-toolkit` |
| typescript-react | kit | TypeScript/React/Next.js: `typescript-reviewer`, `react-reviewer`, `react-build-resolver` agents; skills `react-patterns`, `react-testing`, `frontend-patterns`, `typescript-react-standards` | TypeScript, React, Next.js, component, hook, tsx | `typescript-react@my-toolkit` |
